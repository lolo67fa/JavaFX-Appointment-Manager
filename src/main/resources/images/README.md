# Images

Drop the application icons here. Every icon is optional — if a file is missing the
application falls back to a text-only control.

| File | Used for |
|---|---|
| `logo.png` | Sidebar logo (80x80) |
| `home.png` | Dashboard navigation button (20x20) |
| `personal.png` | Personal category (20x20 in the sidebar, 30x30 in the list) |
| `work.png` | Work category |
| `general.png` | General category |
